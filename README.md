# Web to Markdown

Extensión de Chrome para guardar la página web activa como archivo Markdown.

## Stack

- Chrome Extension Manifest V3
- TypeScript
- React
- Vite

## Desarrollo

```bash
pnpm install
pnpm build
```

Después cargar la carpeta `dist/` desde `chrome://extensions` con el modo desarrollador activado.

## Flujo

1. Abrir una página web.
2. Abrir la extensión.
3. Pulsar "Guardar como Markdown".
4. Elegir dónde guardar el archivo `.md`.
